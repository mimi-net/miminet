## Две группы тестов

Различие определяет всё — от времени прогона до того, можно ли запустить тесты
на ноутбуке.

**Юнит-тесты** проверяют чистые функции: разбор пакетов, валидацию аргументов
заданий, построение VLAN-конфигурации, пути к файлам захвата. Они не поднимают
сеть, не требуют прав и проходят за секунду.

**Тесты эмуляции** запускают настоящий Mininet: создают сетевые пространства
имён, поднимают Open vSwitch, гоняют трафик и сверяют перехваченные пакеты с
эталоном. Им нужен root, установленный Mininet, работающий OVS и собранный
`mimidump`.

Граница проходит по вызову `run_miminet` из `src/tasks.py`. Файл, который его
вызывает без подмены, попадает во вторую группу.

## Юнит-тесты

Ни один не требует root или Mininet. Все 115 проходят примерно за одну секунду.

| Файл | Тестов | Что проверяет |
|---|---|---|
| `test_jobs.py` | 40 | Валидаторы заданий, фильтры опций и обработчики команд из `jobs.py`: белые и чёрные списки аргументов для `ping`, `traceroute` и прочих, сборка итоговой команды |
| `test_pkt_parser.py` | 14 | Классификация пакетов в `pkt_parser.py`: определение типа по содержимому, разбор заголовков |
| `test_vlan.py` | 12 | Конфигурация VLAN в `net_utils/vlan.py`: построение правил для linux-bridge, access- и trunk-порты |
| `test_network_ready.py` | 11 | Гейт готовности захвата в `net_utils/readiness.py`: когда считать, что интерфейсы поднялись и можно начинать снимать трафик |
| `test_tasks.py` | 16 | Чистые помощники `tasks.py` (`_filter_unknown_nodes`, `_has_meaningful_packets`, кеш `get_network_schema`) плюс пути повторов и исключений `run_miminet` — эмулятор при этом подменён моком, поэтому OVS не нужен |
| `test_captures.py` | 3 | Пути к файлам захвата в `net_utils/captures.py`: раскладка `/tmp/capture_*.pcapng`, обход всех концов связей |

## Тесты эмуляции

| Файл | Тестов | Что проверяет |
|---|---|---|
| `test_miminet_back.py` | 21 | Полный прогон эмуляции по каждому сценарию из `test_json/` со сверкой пакетов с эталоном |
| `test_duplication.py` | 3 | Дублирование и потеря пакетов на связях, обратная совместимость сетей без этих настроек |

### Как устроен `test_miminet_back.py`

Ядро всего набора. Работает от данных: каталог `test_json/` содержит пары
файлов `<сценарий>_network.json` (топология на вход) и `<сценарий>_answer.json`
(ожидаемые пакеты). Тест запускает эмуляцию и сравнивает результат.

Прямое сравнение невозможно — эмуляция даёт нестабильные значения, поэтому
перед сверкой применяется нормализация:

- пропускаются ARP- и STP/RSTP-пакеты как малоинформативные;
- динамические номера портов заменяются на `PORT`;
- MAC-адреса в ARP-ответах обезличиваются;
- дубликаты удаляются, список сортируется по пути, источнику и метке.

Покрытые сценарии (21):

`dhcp_no_client`, `dhcp_one_host`, `dhcp_two_host`, `first_and_last_ip_address`,
`icmp_host_unreachable`, `icmp_network_unavailable`, `link_down`,
`port_forwarding_tcp`, `port_forwarding_udp`, `router`, `rstp_four_switch`,
`rstp_simple`, `switch_and_hub`, `tcp_connection_setup_1`, `vlan_access`,
`vlan_trunk`, `vlan_with_access_switches`, `vlan_with_stp`, `vlan_with_vxlan`,
`vxlan_simple`, `vxlan_with_nat`.

Добавить новый сценарий — значит положить в `test_json/` пару файлов; менять код
теста не нужно.

## Запуск

### Юнит-тесты — локально, без всего

```sh
uv sync --project back
cd back/tests
PYTHONPATH=../src uv run pytest \
    test_captures.py test_jobs.py test_network_ready.py \
    test_pkt_parser.py test_vlan.py test_tasks.py
```

Ожидаемо: **115 passed примерно за секунду**. Ни root, ни Mininet, ни
контейнеров не требуется.

### Тесты эмуляции — нужен root и Mininet

```sh
sudo bash
source .venv/bin/activate
cd back/tests
export PYTHONPATH=$PYTHONPATH:../src
pytest .
```

Без root падает сразу: `Mininet must run as root`. Кроме прав нужны
установленный Mininet, запущенный Open vSwitch (`back/ovs-init.sh`) и собранный
[mimidump](https://github.com/mimi-net/mimidump).


### CI

`.github/workflows/back_test.yml` запускается на push и pull request. Готовит
окружение целиком: ставит Mininet, OVS, `iproute2`, `dnsmasq` и прочее, собирает
`mimidump` из исходников, отключает передачу пакетов bridge-фильтрам через
`sysctl`, поднимает OVS через `back/ovs-init.sh`.

Тесты разбиты на 3 шарда по остатку от деления номера файла и выполняются под
`coverage` в branch-режиме. Отдельная задача `coverage` собирает данные шардов
вместе и требует покрытия не ниже 75% (базовая линия на main — 76.15%).
Частичное объединение считается ошибкой: если пришло меньше файлов, чем шардов,
задача падает, чтобы неполный отчёт не скрыл регрессию.

Настройки pytest (`back/tests/pytest.ini`): `-vv`, таймаут теста 900 секунд, лог
пишется в `back_test.log`.

## Пробелы и наблюдения

**Шардирование не различает типы тестов.** Файлы делятся по остатку от деления
номера, поэтому юнит-тесты и тесты эмуляции перемешаны между шардами. Полная
инфраструктура — Mininet, OVS, сборка `mimidump`, правка `sysctl` — ставится на
всех трёх раннерах, хотя нужна лишь части файлов. Разделение на быструю
юнит-задачу и медленную эмуляционную сократило бы время обратной связи: 115
тестов проходят за секунду и могли бы сообщать о поломке до того, как поднимется
эмулятор.

**Эталоны эмуляции хрупки по своей природе.** Сравнение идёт с записанными
ответами, а нестабильные части гасятся регулярными выражениями в
`test_miminet_back.py`. Любое изменение формата пакета требует либо новой
подстановки, либо перегенерации всех 21 эталона. Сейчас подстановок пять, и
список будет расти.

**Нет негативных сценариев эмуляции.** Проверяется, что сеть работает как
задумано; поведение при сбое эмулятора, зависании узла или частично поднятой
топологии не покрыто. Исключение — `test_tasks.py`, где пути повторов и
исключений проверяются на моках.

**Тесты эмуляции не изолированы друг от друга.** `test_miminet_back.py` чистит
`/tmp/capture_*.pcapng` перед каждым запуском именно потому, что файлы захвата
общие. Параллельный прогон в пределах одного раннера сломался бы, поэтому
ускорять эту группу через `-n` нельзя — только через разделение по раннерам.

**Покрытие измеряется, но только для `back/src`.** Гейт в 75% защищает от
регрессии, однако он усреднён по всему пакету: модуль, покрытый плохо, может
прятаться за хорошо покрытым.
